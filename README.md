## What it does

`main.py` (Python 3, no network, no dependencies) writes a single line —
1 to 240 characters — in the voice of the Moon, replying at last to the
wishes, howls and late-night promises of everyone staring up at it, to
`/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: repeated runs produce byte-identical files.
